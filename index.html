💾 ข้อมูล & สำรอง

ข้อมูลพอร์ตของคุณจัดเก็บอยู่ในเครื่องนี้เท่านั้น หากล้างแคชเบราว์เซอร์หรือเปลี่ยนอุปกรณ์ ข้อมูลจะไม่ถูกโอนย้ายให้โดยอัตโนมัติ จึงแนะนำให้สำรองข้อมูลเป็นไฟล์ JSON อย่างสม่ำเสมอ (ไฟล์สำรองไม่รวม API Key เพื่อความปลอดภัย)

🔒 ล็อกหน้าจอด้วย PIN

ยังไม่ได้ตั้งค่ารหัส PIN

⚠️ คุณสมบัตินี้เป็นเพียงการล็อกหน้าจอเบื้องต้นเพื่อป้องกันการเข้าถึงโดยบุคคลอื่น มิใช่การเข้ารหัสข้อมูล ข้อมูลที่จัดเก็บในเครื่องยังไม่ได้ผ่านการเข้ารหัส ผู้ที่สามารถเข้าถึงไฟล์ระบบของอุปกรณ์โดยตรงจะยังสามารถเข้าถึงข้อมูลดังกล่าวได้

จำเป็นต้องตั้งค่ารหัส PIN ไว้เป็นช่องทางสำรอง สำหรับกรณีที่ไม่สามารถยืนยันตัวตนด้วยไบโอเมตริกซ์ได้ กระบวนการยืนยันตัวตนดำเนินการภายในอุปกรณ์ผ่านเซนเซอร์โดยตรงเท่านั้น ไม่มีการส่งข้อมูลออกนอกเครื่อง ทั้งนี้คุณสมบัตินี้มีลักษณะเป็นการล็อกหน้าจอเช่นเดียวกับรหัส PIN มิใช่การเข้ารหัสข้อมูล
